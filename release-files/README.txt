Dragonwilds Toolkit v{VERSION}
===========================

1. Quit RuneScape: Dragonwilds.
2. Double-click {EXE}.
   If Windows says "Windows protected your PC": click More info, then Run anyway.
3. First start: the toolkit finds the game on any drive and builds its library by itself
   (about a minute). If it can't find the game, click Browse and pick the game folder.
4. Edit, then click "Review & save". A backup is made automatically before every save.

Everything is inside the exe, including the Live cheats loader: nothing else to install.
(When you're online, building the library also fetches extra item stats; it works without them.)
You only need:
  - RuneScape: Dragonwilds installed on this PC (item names and pictures come from it)
  - Windows 10 or 11 (Microsoft Edge WebView2, which almost every PC already has;
    the toolkit tells you if it's missing)
  - To have played the game once, so a character save exists

Menu:
  Character - Inventory, Skills, Stats, Unlocks
  World     - World map (chests, teleport, organizer), Items
  Tools     - Live cheats, Presets, Share (give/install worlds), Backups

Saving only works while the game is closed. Live cheats work while the game runs
(install them once from the Live cheats tab; uninstall removes them).
Hosting with friends: Live cheats > Players in your world lists everyone in your world.
Give them cheats, items, heal them, bring them to you, send them to their latest
gravestone, send them anywhere (right-click the World map), speed them up, let them fly
or freeze them. Their live
positions show on the World map. Only the host needs the toolkit for this.
Numpad keys in game: 1 health+stamina, 2 carry 99999, 3 refill food/water/rest, 4 heal,
5 durability, 6 no hunger, 7 speed, 8 damage x10, 9 latest gravestone, . back after teleport,
0 all back to normal, + flying, - home, / set home here, * hide/show top bar.
New features (teleport, moving gravestones, unlocks, adding items) are marked
"check in game" - try them once and restore a backup if anything looks wrong.

Updating: the toolkit tells you when a new version is out (gold bar at the top). Download
it, delete the old exe and use the new one. Your library, backups and settings
are kept in %LOCALAPPDATA%\DragonwildsSaveEditor and carry over.
Your game saves: %LOCALAPPDATA%\RSDragonwilds\Saved
